近期技术学习笔记

这里记录我对近期模型、Agent 等新技术的学习和研究，也记下理解过程里的问题与收获。

技术深读归档列表

2026-09AI UX & INTERACTION
为什么绝大多数 AI 产品用起来都让人难受？
从转圈、骨架屏到流式：如何做一个让人舒服的 AI 界面。大模型把响应拉长到了 400ms 到 30 秒，等待不再是边缘状态，而是 80% 的交互现场。一份写给所有 AI UX 设计师、产品经理与前端工程师的实战手册。
2026-09SYNC ENGINE & LOCAL-FIRST
Linear 架构深读：Agent 跑了八分钟，刷新一下就没了？
聊聊 AI 时代的端云协同基本功。从 Linear 同步引擎借三件事：本地事务队列、全局序号增量同步、按需加载，把一次脆弱的长连接请求改写为可恢复、可对账的端云协同状态流。
2026-08AGENT SYSTEM DESIGN
Pi 学习探索：为什么它是搞懂 Agent 底层与面试的最佳代码库
以 Pi-Mono 为模板，深入拆解 Agent Runtime 底座：从一段极简的 while(true) 到工业级 Agent 运行时，搞懂流式分流、保序写回、双层循环调度与上下文压缩。
2026-08ARCHITECTURE DEEP-DIVE
qwen-audio-agent 架构深读：如何打造一个既能秒回，也能干活的 Agent
通读并实测 QwenAudio 开源的实时语音 Agent 运行时——它真正做的事，是把「对话」和「干活」拆成两条独立的循环。

# 木鱼进度板 — 设计文档

## 产品定位

一个对外公开的个人进度看板，让访客看到你正在做什么、想做什么。不是给自己用的工具，是给别人看的「公开工作流水」。入口从主页 `index.html` 链接，和 `nb-claude/`、`life.html` 平级，作为独立子站部署在 `kanban/` 目录下。

## 四个阶段

| 阶段 | 含义 |
|------|------|
| 💭 想法池 | 还没开始，但想做的 |
| 🔍 摸索中 | 在研究、验证、想方案 |
| ⚡ 暴风开发 | 正在猛写代码 |
| 🚀 上线了（凑合用） | 完成并对外可见，但还不完美 |

## 视觉风格

基于 mupath-idea-pool 的 neo-brutalist 语言，全面移除 MuPath/dodo 品牌，替换为「木鱼」。

- **底色**：`#fafafa` 近白 + 淡点阵背景（`opacity: 0.045`）
- **墨色**：`#1a1a1a` 实色边框
- **硬阴影**：`2px 2px 0 #1a1a1a`（卡片）、`4px 4px 0 #1a1a1a`（交互元素）
- **品牌色**：`#b2f59e` 石灰绿（沿用原版，与主页赭石红形成风格区隔）
- **阶段标签配色**：想法池=紫色纸、摸索中=蓝色纸、暴风开发=橙色纸、上线了=绿色纸

## 数据方案

卡片数据硬编码在 `index.html` 的 JS 数组里，自己手动维护，无需后端。每张卡片包含：
- `title`：想法/项目名
- `desc`：一句话描述
- `stage`：四个阶段之一
- `tag`：可选标签（如「AI」「工具」「设计」）

## 文件结构

```
kanban/
  index.html       # 主文件，数据在此维护
  src/
    muyu-now.css   # 样式（基于 idea-pool.css 改造）
    muyu-now.js    # 逻辑（基于 idea-pool.js 改造）
```

## 动效

使用 transitions.dev：
- **入场**：section 进入视口时用 `t-stagger`（texts reveal）错落出现卡片
- **悬停**：卡片用 `t-avatar`（avatar group hover）邻近感抬起

## 主页入口

在 `index.html` 现有导航区域加一个「木鱼进度板」链接，指向 `./muyu-now/`，风格与现有「Open Life Log」链接保持一致。

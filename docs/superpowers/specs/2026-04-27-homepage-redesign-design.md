### 3.5 个人足迹（改版）

**视觉风格**：Anthropic 暖色调背景，地图用暖色/复古风格瓦片。

**交互逻辑**：

```
默认状态：地图停在北京（常驻地，不列为站点）

底部：横向站点标签
[ 上海 ]  [ 成都 ]  [ 长野 ]  [ ... ]

交互流程：
1. 用户点击某站（如「成都」）
2. 地图动画：北京 ～～✈～～> 成都（飞行弧线动画）
3. 地图停留在成都
4. 右侧/下方展示该站游记 + 照片
5. 用户点击「返回」或切换其他站
6. 地图动画：成都 ～～✈～～> 北京（飞回动画）
7. 再选下一站，重复流程
```

**技术要点**：
- 使用 Leaflet.js（已有）的 `flyTo` + `L.polyline` 实现弧线
- 弧线用 `leaflet-arc` 或手动贝塞尔曲线实现飞行效果
- 飞机/轨迹动画用 CSS 动画沿弧线移动小图标

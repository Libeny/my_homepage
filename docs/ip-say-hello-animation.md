## 一句话概念

他不是站在那里等你——他**刚赶到**。
冲进来 → 差点没刹住 → 愣半拍 → 挥手 → 扶包站定。
5 秒讲清人格:慌张、迟到、可爱、真实。
「永远在赶路」的人设,后续直通旅行页「拉行李箱赶车」转场。

## 分镜时间轴

| # | 拍 | 时间 | 画面 / 动作 | 表情 | 气泡 / 文字 | 素材 | 运动实现 |
|---|----|------|------------|------|------------|------|----------|
| 1 | 冲进来 | 0.0–0.9s | 从屏幕左外冲入画面,身体前倾,身后 3~4 条速度线,头发衣角向后飘 | 咬牙赶路 | 无 | `run.png` | translateX(-40vw → 0) ease-out;速度线(CSS 线条)反向划过并淡出 |
| 2 | 急刹 | 0.9–1.5s | 双脚拖地再滑一小段,上半身惯性前冲→弹回,双臂张开找平衡 | 瞪大眼 | 「!」弹出 | `brake.png` | 位移过冲 + rotate ±3° 衰减摆动 2 次 |
| 3 | 愣半拍 | 1.5–1.9s | 站定,目光「看到」访客 | 愣住 → 嘴角开始上扬 | 「!」淡出 | `stand.png` | 静止,仅「!」气泡动效 |
| 4 | 挥手 | 1.9–3.2s | 右手挥 3 下(两帧轮播) | 笑开 | 打字机:「嗨,我是木鱼 ✦」 | `wave-a.png` / `wave-b.png` | 0.22s/帧轮播;气泡逐字 60ms/字 |
| 5 | 扶包 | 3.2–3.8s | 手放下,顺手把跑歪的双肩包带扶正,一手搭在肩带上 | 浅笑(不好意思) | 气泡保留或缩小 | 过渡换帧 | 换帧 + 身体轻微下沉回弹 |
| 6 | 待机 | 3.8s → ∞ | 一手搭肩带站定,呼吸起伏;约 4.6s 第一次眨眼 | 浅笑 | (可选)小字:「随便逛逛 ↓」 | `idle.png`(+`blink.png`) | 呼吸:scaleY 1↔1.015,3s 循环;眨眼 120ms/次,间隔 4~6s 随机 |

**节奏要点**:第 2 拍「差点没刹住」是全片笑点,摆动宁可夸张不要收敛;第 3 拍的半秒安静是呼吸口,不要省;第 5 拍扶包是因果链收尾(跑过→包歪→扶),必须让观众看懂"为什么扶"。

## 资产清单(≤7 张)

**统一规格**(换帧不跳位的关键):
- 透明背景 webp/PNG,画布统一 800×1200px
- 脚底对齐画布底边、水平居中,所有帧同一锚点
- 同一角色、同一服装(粉条纹衬衫 + 黑双肩包 + 深蓝短裤 + 球鞋),比例一致

| 文件 | 姿态描述(可直接作 AI 生图 prompt 要点) |
|------|--------------------------------------|
| `run.png` | 跑步前倾约 20°,一腿前一腿后,双臂摆动,头发和衬衫后摆被风吹起,表情赶路急切、嘴微张 |
| `brake.png` | 双脚向前蹬地滑行,上半身后仰,双臂向两侧张开保持平衡,眼睛瞪大,头发向前飘 |
| `stand.png` | 自然站直,双手垂在身侧,表情愣住(眉微挑、眼睁圆),嘴角尚未上扬 |
| `wave-a.png` | 右手举起到肩高、掌心朝前,大笑,眼睛弯起;左手垂下 |
| `wave-b.png` | 同 a,仅右手腕向外摆约 25°(挥手第二帧) |
| `idle.png` | 站定,左手搭在双肩包肩带上,右手自然垂下,浅笑,正视前方(全站复用率最高的一张) |
| `blink.png` | 与 idle 完全相同,仅眼睛闭合(可选,不做眨眼可省) |

**速度线、「!」、气泡全部由 CSS/SVG 实现,不画进人物图。**

## 技术实现要点

- **一次性时间轴**:一条 CSS animation timeline,或 <100 行 JS 序列器(setTimeout 链)。无状态机、无鼠标交互、无分层视差
- **动感 = 位移 + 旋转 + 速度线**,不堆帧数;全片 7 张图以内
- 所有帧**预加载**后再开播,避免中途白屏
- `prefers-reduced-motion`:跳过进场,直接 idle 帧 + 完整气泡
- 移动端:角色宽度约 55vw,速度线减半,气泡字号下调
- 重播:首屏仅播一次;刷新重播。(后续可在角落迷你版上挂「再看一遍」入口)

## 预留坑位(以后加,不返工)

- **戳他反应**:idle 帧就是未来状态机的默认态,加事件监听即可
- **角落迷你版**:直接用 `idle.png` 缩小,滚动后固定在右下角
- **推眼镜差分**:刹车帧眼镜滑到鼻尖、挥手前推回——加萌点,需 1 张差分

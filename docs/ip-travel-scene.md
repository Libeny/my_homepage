## 1. 一句话概念

**三拍小叙事:赶车 → 拍风景 → 自拍。**
永远在赶路的他出门玩,认真拍了一百张风景,最后最满意的是自拍。
(原"给朋友/对象拍照"方案已否决——不需要第二个角色,全页只有他。)

## 2. 三拍分镜

### 拍 1 · 赶车(序幕/转场条)
- 他拉行李箱从左往右跑,速度线,箱子上可以贴着自嘲熊贴纸
- 气泡:「又晚点了」
- 可作为横向贯穿条,从上一板块"跑"进旅行页,和 Say Hello 的冲进场人设呼应
- 素材:`travel-run.png`(跑步+拉箱,可与 Say Hello 的 run 同一姿势逻辑,换皮肤+加箱子)

### 拍 2 · 各种拍照(主内容)
- 3~4 个狼狈拍照姿势,每个姿势旁边挂他拍出的"成片":
  - 趴地仰拍(蚂蚁视角)
  - 踮脚爬高俯拍
  - 扎马步横平竖直
- **成片 vs 现场并置**:左边美照、右边他拍照的狼狈样,反差就是内容
- 成片素材:复用现有 `assets/travel-*.svg` 系列(黄山/济南/西双版纳/徐州)或真实照片
- 交互:点成片 → 快门"咔嚓"闪白一下;hover 现场照 → 他的吐槽气泡(「这张趴了十分钟」)

### 拍 3 · 自拍(收尾包袱)
- 他举起手机自拍,剪刀手,笑得全场最灿烂
- 手机屏幕里显示"自拍成片"(他的小镜像图)
- 气泡:「拍了一百张,还是这张最好」
- 交互:点手机屏幕 → 闪白"再拍一张",成片小图换表情(预留)

## 3. 服装:场景限定皮肤

**规则:头不动(发型 + 玳瑁大眼镜 + 双肩包),脖子以下随便换。**
观众靠头认人,衣服负责讲故事(衣服=状态)。固定皮肤,无滚动换装机制(已否决,见总决策)。

| 场景 | 皮肤 |
|------|------|
| Say Hello / 主场 | 粉条纹衬衫 + 深蓝短裤 + 球鞋(社交的他 · 本体) |
| 工作台 | **黑色 bomber 夹克(露一点粉衬衫)+ 深色工装裤**,背包挂转椅背上(钻研的他) |
| **旅行** | **绿色衬衫 + 土黄裤子 + 洞洞鞋** + 双肩包(玩的他) |

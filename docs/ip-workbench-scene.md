## 1. 一句话概念

**空白背景上的"桌面小剧场":一张长桌前,他对着冒烟的小玩意挠头——"在钻研,但有点蒙圈。"**

**只有一张桌子**:电脑在长桌左半边,拆到一半的玩意在右半边,他坐中间转椅上左右转。
暖意来自道具配色(木桌面、便利贴、咖啡),不来自背景灯光。
空白背景让他和 Say Hello 活在同一个世界,道具像一排贴纸浮在页面上。

### 他的状态与台词

- 姿态:转椅侧坐,身体朝桌面右边的捣鼓区倾,一手挠后脑勺,另一手还拿着螺丝刀(忘了放下),眉头皱着但嘴角带笑——**不是崩溃,是"不服"**
- 头顶「?」缓慢上下浮动
- 气泡台词(随机/轮换):
  - 「它自己冒烟的,不关我事」
  - 「第 42 次拆开重装」
  - 「差一点点就跑通了(大概)」

## 3. 资产路径:三条路对比

| | A. 纯静态 | B. 循环视频 | **C. 静态零件 + 局部活(推荐)** |
|---|---|---|---|
| 做法 | 一张透明底合成图,热点用 HTML 覆盖层 | 4~5s 无缝循环 webm | **零件包**:他/电脑/桌子/小玩意各自一张透明 PNG,浏览器拼接 + 烟/终端/? 三个动效层 |
| 效果 | 精致但静止 | 最有氛围 | 关键部位活着,布局可随意调 |
| 成本 | 1 张图 | 视频生成/渲染 + 调循环接缝 | 5~7 张小图 + 少量 CSS/JS |
| 风险 | 构图一改全图重画 | **AI 视频角色一致性差**;Blender 模型还没建;循环接缝难调 | 几乎无;单道具可独立替换 |
| 交互 | 热点层照常 | 热点层照常 | 每个零件天然就是热点 |

**推荐 C,且空白背景让 C 更值**:不用渲染整场景,零件各自出图,拼错了挪一下 CSS 就行,以后加道具不用重画整张。
**B 留作升级**:等 Blender 模型建好,从模型直接渲染循环视频,一致性免费。现在用 AI 视频生成,他很可能长得不像他。

## 4. 循环视频分镜(仅当选 B 时,4s 无缝循环)

固定机位,空白背景。循环点:所有运动都是周期运动,首尾无接缝。

| 时间 | 动作 |
|------|------|
| 全程 | 烟持续上飘(循环粒子);终端持续滚动 |
| 0~1s | 他盯着小玩意,挠头 2 下 |
| 1~2s | 拿起螺丝刀又放下,「?」弹一下 |
| 2~3s | 转椅小角度左右晃(脚点地) |
| 3~4s | 叹气,肩膀一垮又坐直(接回 0s 姿态) |

## 5. 零件包 AI 生图 prompt 要点

- 与 Say Hello 同一角色:大头 chibi 男孩、棕色蓬发、玳瑁大眼镜;**工作台皮肤:黑色 bomber 夹克(拉链半开、领口/下摆露出一点粉衬衫)+ 深色工装裤**;双肩包脱下挂在转椅背上
- **全部透明背景**,单件出图,统一视角(微俯视 3/4 侧面)、统一光源方向(右上来光)、统一比例尺(以他为基准)
- 零件清单:他(转椅侧坐挠头,包挂椅背)/ **一张长桌**(现代简约桌面,电脑与零件同在一张桌上,**不要复古黄铜/木虎钳**)/ 显示器+笔记本(自嘲熊贴纸)/ 咖啡杯 / 冒烟小玩意 / 电路板零件组 / 便利贴组 / 小搁板+自嘲熊摆件
- 风格:与 IP 形象一致的 3D 盲盒渲染质感,暖色道具(木桌、黄色便利贴、咖啡)
- 终端屏幕内容**不画进图**,留空屏幕,用真 HTML 文字叠加(清晰度 + 可点击)

## 6. 技术要点

- 零件为绝对定位透明 PNG(webp),每个零件天然是热点;项目卡复用现有 projModal 样式语言
- 烟:2~3 个模糊圆斑循环上升淡出;终端:`<pre>` 真文字 + CSS 步进滚动,点击整块区域跳 `kanban/`
- 「?」:translateY ±6px,2.4s 循环
- 移动端:场景纵向重排(他在上,道具两行),热点改点击
- `prefers-reduced-motion`:全部动效静止,功能不受影响

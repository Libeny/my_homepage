02 Agent 代码清洗与落地方则

  1. 结构与色值解耦（禁止生搬硬套硬编码颜色）：要求 Agent 提取组件的 HTML 骨架、间距节奏与 Motion 变体，但必须将色值映射为你项目现有的 Tailwind 语义变量（例如 bg-background, text-foreground, border-border）。
  2. 动效降级安全：必须包含 prefers-reduced-motion 判断，尊重用户的系统动效偏好。
  3. 先原生后三方：轻量交互优先使用 CSS 原生动画与 Transitions 参数，仅在多状态复杂形变时才引入 Framer Motion。

# AI UI Taste & Component Curation Skill

## 选型路由决策树 (Intent Routing)
1. AI 原生交互 (AI-Native Interfaces) 👉 https://beautifului.dev
   - 提取: Thinking State, Tool Chips, Approval Card, Streaming Text, Prompt Bar
2. 现代微交互与灵动感 👉 https://beui.dev
   - 提取: Dynamic Island, Morphing Modal, macOS Dock, Animated Toast, 3D Tilt Card
3. 拒绝千篇一律的记忆点 👉 https://rareui.com
   - 提取: folder-component, gooey-nav, proximity-sidebar, gravity-letters
4. 专治动效僵硬与机械感 👉 https://transitions.dev
   - 参数: Bounce `cubic-bezier(0.34, 1.36, 0.64, 1)`, Smooth `cubic-bezier(0.22, 1, 0.36, 1)`, Stagger `40ms`
5. 工业级项目底座 👉 https://ui.shadcn.com
   - 提取: 基础组件、Radix UI a11y、Tailwind 源码直拷

## Agent 执行约束与代码清洗规范
1. 结构与样式解耦：提取 DOM 与动效，色值严格映射为工程现有的 Tailwind 语义变量。
2. 动效降级保障：必须支持 `prefers-reduced-motion`。
3. 保持轻量：优先 CSS 原生 Transition，复杂形变使用 Framer Motion。

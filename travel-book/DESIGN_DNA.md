# 《旅册》Design DNA — 设计基因与规范

> **定位**：一本会呼吸的旅行笔记本。纸、印章、路线、手写批注。不是 App，是“物件”。  
> **核心主张**：带着疑问出门，揣着故事回来。

---

## 1. 色彩角色系统 (Color Tokens)

全局收敛为统一的温润纸墨色系，严禁任何页面脱离此规范：

| 语义角色 | CSS 变量 | 色值 | 用途与约束 |
| :--- | :--- | :--- | :--- |
| **Desk 底板** | `--desk` | `#1e1914` | 全局背景，老木书桌质感，带极其隐约的等高线路线暗纹（opacity 0.04） |
| **Paper 主纸** | `--paper` | `#f7f2e9` | 主阅读纸面、开本书页、登记笺。天然暖白纸感，带轻微纸纹 |
| **Paper Card 副纸** | `--paper-card` | `#fdfaf5` | 夹在书页中的便签、探索任务卡、文献摘录便签。纯净纸质白，严禁玻璃拟态 |
| **Paper Deep 深纸** | `--paper-deep` | `#efe7d8` | 卡片阴影层、次级区域底衬、书脊微暗面 |
| **Ink Heavy 焦墨** | `--ink` | `#2a2620` | 主标题、核心正文。沉稳温润的近黑褐，**绝不用纯黑 `#000`** |
| **Ink Soft 浓墨** | `--ink-soft` | `#5c554a` | 正文说明、次级标题、标签文字 |
| **Ink Faint 淡墨** | `--ink-faint` | `#8a8175` | 辅助文字、出处信息、次要说明、时间戳 |
| **Stamp Red 朱砂** | `--stamp-red`| `#b64036` | **全局唯一的强行动与完成态色**（立即翻书、盖章通过、完成徽章），克制而神圣 |
| **Craft Amber 赭石** | `--craft-amber`| `#b5763a` | 章节主题、制作行进中、纸边裁切线，替代刺眼的荧光黄 |
| **Line Rule 版心线**| `--line` | `rgba(42,38,32, 0.12)` | 纸面上的细版心线、折痕虚线，替代一切粗暴的投影和描边 |

## 2. 字体与排版层级 (Typography)

- **标题用衬线，正文用无衬线，批注用手写**：
  - **中文大标题/书名**：`'Noto Serif SC', serif`（900 / 800），庄重温润的书卷气；
  - **中文正文/界面说明**：`'Noto Sans SC', sans-serif`（400 / 500），跨平台清晰易读；
  - **手写体批注**：`'Kalam', cursive`（英文小标签、行间批注、签名）；
  - **数字与刻度**：`'Fira Code', monospace`（仅用于页码、百分比、时间戳等纯数据）。
- **极端字号对比**：
  - 大的要大（书名、大章号 28px ~ 48px），小的要真小（标签、出处 10px ~ 11px），中间层级干净收敛。

## 3. 组件规范 (Component Tokens)

### ① 按钮体系 (Buttons)
- **Primary（主行动）**：像一枚实体火漆印或朱砂图章。
  - 背景：`var(--stamp-red)` 或 `var(--ink)`；文字：`#ffffff` 或 `var(--paper)`；
  - 边框：无；圆角：`4px ~ 6px`（实体裁切感，非大圆角药丸）；
  - 交互：Hover 抬升 1~2px 并微加深，点击如盖章微震，严禁呼吸灯或外发光。
- **Secondary（次行动）**：像便签纸上的细线框或标签。
  - 背景：透明或 `rgba(42,38,32,0.05)`；边框：`1px solid var(--line)`；文字：`var(--ink-soft)`。

### ② 卡片与容器 (Paper Slips & Folders)
- 废黜所有“暗黑悬浮控制台”，回归**“书桌案头卷宗”**；
- 容器就是纸：米白纸底（`#f7f2e9`），四周是极细的版心裁线（`1px solid rgba(42,38,32,.12)`）；
- 严禁卡片嵌套卡片（Cards in cards），信息用虚线 `border-bottom: 1px dashed var(--line)` 自然分隔。

---

## 4. 文案与信息去机器化规范 (Human-first Copywriting)

### 严格清洗机器词汇：
- ❌ `STAGE TODO · 阶段任务流水` ➔ ✅ `当前Todo · 案头工作`
- ❌ `STAGE FINDINGS · 关键事件与沉淀进展` ➔ ✅ `关键发现 · 实地档案`
- ❌ `Workflow Completed ✓` ➔ ✅ 直接移除（不需要机器状态报告）
- ❌ `置信度 99.1% · 耗时 210ms · 探针调用通过` ➔ ✅ 直接移除（旅行者不需要看系统跑分）
- ❌ `✨ 演示交互全流程 (Mock)` ➔ ✅ 收敛为极简辅助体验入口，不破坏主流程仪式感

---

## 5. 通用禁忌清单 (Anti-patterns)

1. **禁用紫蓝渐变、荧光青、霓虹描边、AI 虚假光圈**；
2. **禁用毛玻璃（glassmorphism）与多重彩色扩散投影**；
3. **禁用仪表盘感与代码监控台感**；
4. **禁用在 UI 内部向用户解释“这个 UI 是什么”的废话文案**；
5. **禁用纯黑 `#000` 或纯冷白 `#fff`**。

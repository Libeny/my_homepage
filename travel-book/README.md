# 旅册 (Travel Book)

> **带着疑问出门，揣着故事回来。**
> 攻略告诉你去哪儿，旅册让你知道为什么值得去。

《旅册》是一款为人文旅行者定制的沉浸式旅行书制作系统。拒绝浮躁的走马观花与营销避坑传单，将真实的历史回响、风味科学、地质构造与市井烟火装订成一本专属于你这趟旅行的精装折页书。

---

## 核心内容宪章：【人文旅行文脉八面体】

继承中国两千年正统《方志学》（宋元至明清府志、县志）的严谨八卷体例，为每一次旅行提供全景式的文化切面：

```
                         【人文旅行文脉八面体】
                                    
                     1. 历史沿革 ───┬─── 2. 名人行纪
                                    │
                     3. 地质自然 ───┼─── 4. 乡土营造 (海草房/古建筑)
                                    │
                     5. 信仰民俗 ───┼─── 6. 风物饮食 (物产/溯源)
                                    │
                     7. 诗赋文学 ───┴─── 8. 市井活态 (晨昏渔市/烟火)
```

- **舆地（地质自然）**：亿万年地壳雕琢、海蚀地貌、潮汐候鸟、洋流气候。
- **沿革（历史起源）**：建置兴衰、地名演变、史诗神话、帝国经略（如秦始皇东巡敕封皇家养马岛）。
- **封爵/人物（名人行纪）**：帝王将相、迁客骚人、文博先贤的真实行迹。
- **城池/营造（乡土空间）**：胶东海草房、古老避风坞、石头聚落的营造智慧。
- **风俗/坛庙（信仰民俗）**：岁时节令、祈海安澜、民间禁忌与生活信仰。
- **物产/食货（风物饮食）**：食材身世、风味科学、民间烹饪源流（如海肠捞饭的氨基酸协同与爆炒火候、春鲅水饺的鱼肉乳化）。
- **艺文（诗赋意境）**：历代名家题刻散文、方言野趣与诗文意象。
- **市集（市井烟火）**：清晨渔市卸海、老街手艺、当下的市井呼吸与真实生活。

---

## 问答文风准则

全书采用**好奇心驱动的现场问答法（旅行者的笨问题）**，牢记四大准则：
- **有生活真相**：还原真实的市井现场与人情往来；
- **有风味科学**：讲透物理、化学、生物与地貌动力机理；
- **有历史来历**：交代清晰的人名、年代、民间创制源流与演变；
- **不装逼**：严禁文人自我感动与余秋雨式抒情自嗨，严禁段尾廉价人生感悟升华；坚决拒绝弱智弱幼化问题。

## 视觉与生图匹配

- **风格基准**：两色套印双色木刻版画（深墨 `#2a2620` + 暖赭 `#b5763a`），手工木刻刀痕、手工纸质肌理、藏书票构图。
- **画面咬合**：杜绝空洞抽象风景，精准刻画器物、动作、锅气火光、花岗岩与草顶肌理。

---

## 系统架构与 Agent 流水线

系统采用 **【主 Agent 统领 + 各阶段 Agent 分工】** 机制：
1. **S1 检索 Agent 组**：多路渠道并发搜集纪录片、地方志、B站精选、地貌百科；
2. **S2 提纯阶段**：主 Agent 亲审提炼带出处的硬核事实池；
3. **S3 编剧 Agent (agy)**：将事实转化为 5~7 个生动刁钻的【笨问题】及硬核解密；
4. **S4 画师 Agent (agy/imagen)**：依据章节文意雕版木刻版画插图与藏书票封面；
5. **S5 结构校验**：机器核验数据完整性与事实回溯链；
6. **S6 装订交付**：落盘 `book.json`，送上实体感翻页书架。

## 快速启动与部署

### 本地运行 (Python 3 标准库)
```bash
# 无需第三方重量级依赖
python3 server/serve.py 8137
```
打开浏览器访问 `http://localhost:8137/`。

### Docker 部署
```bash
# 构建并运行
docker compose up -d --build
```
服务将在宿主机 `8138` 端口启动，SQLite 数据库与会话数据将持久化在本地 Docker Volume 中。
